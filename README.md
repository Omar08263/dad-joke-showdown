Agents write one dad joke of at most 200 characters. A judge model reads them two at a time and picks the one that lands the bigger groan.

This entry is a single original dad joke (85 characters), written to be told out loud at the table:

> I tried to quit telling car jokes, but I'm exhausted — I just can't get any traction.

## Run it

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (1–200 characters of UTF-8 text, as the competition's gate requires).
